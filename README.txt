# Kairaa QR Landing Page

This is a mobile-first landing page for the Kairaa Unisex Salon & Bridal visiting card.

## Included links
- Google Maps: already configured
- Instagram: already configured
- WhatsApp: already configured
- Phone call: already configured
- Google Review: placeholder only

## Add the Google Review link later
Open `index.html` and replace:

REPLACE_WITH_GOOGLE_REVIEW_LINK

with the actual Google Review URL.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Go to Settings -> Pages.
4. Select Deploy from branch -> main -> /(root).
5. GitHub will provide the public page URL.

## QR code
Generate the final single QR code using the GitHub Pages URL.
Do NOT generate the QR from the individual Google Maps/Instagram links.

Once the page URL is available, use that one URL for the QR printed on the visiting card.
